# Structural Bioinformatics

A computational structural biology project exploring the structure and molecular interactions of human histone H3.

## Project objectives

- Structural analysis of histone H3
- Binding site analysis
- Protein–ligand docking
- Analysis of protein–ligand interactions

## Methods and tools

- Python
- RDKit
- BioPython
- PDB
- AutoDock Vina
- PyMOL
- scikit-learn

## Project status

Currently in development.
